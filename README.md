# CastolinApp — Certificate Generator

**CastolinApp Certificate Generator** — десктопное приложение на Python для автоматического создания сертификатов качества продукции Castolin Eutectic на основе данных из Excel-таблицы.

Программа разработана для автоматизации процесса оформления сертификатов на сварочные материалы, порошки и керамику. Вместо ручного переноса информации из таблиц пользователь может получить готовый документ, указав только номер партии и выбрав тип продукции.

## Возможности

- **Автоматическое создание сертификатов** по номеру партии.
- **Поддержка трёх типов продукции:** сварочные материалы, порошки и керамика.
- **Интеграция с Google Drive** для получения актуальной Excel-таблицы с исходными данными.
- **Автоматический поиск партии** и извлечение характеристик соответствующей продукции.
- **Формирование Word-документов (.docx)** с информацией о продукции, химическом составе, механических свойствах и других характеристиках.
- **Генерация различных шаблонов сертификатов** в зависимости от категории продукции.
- **Графический интерфейс на Tkinter** с выбором типа сертификата, вводом номера партии и отображением процесса выполнения.
- **Сохранение готовых документов** в выбранную пользователем папку.

## Принцип работы

1. Пользователь запускает приложение, выбирает категорию продукции и вводит номер партии.
2. Программа подключается к Google Drive и загружает последнюю обновлённую Excel-таблицу из заданной папки.
3. С помощью библиотеки Pandas выполняется поиск строки с указанным номером партии.
4. Найденные данные используются для автоматического заполнения соответствующих полей сертификата.
5. На основе выбранного типа продукции формируется Word-документ с необходимыми таблицами, характеристиками и оформлением.
6. Пользователь выбирает место сохранения готового сертификата.

## Технологии

**Язык:** Python

**Основные библиотеки:**
- Tkinter — графический интерфейс.
- Pandas — чтение и обработка Excel-таблиц.
- Google Drive API — получение актуальных исходных данных из облачного хранилища.
- python-docx — создание и форматирование сертификатов в формате Word.
- Pillow — работа с изображениями и графическими ресурсами.
- Requests — загрузка внешних графических элементов.
- Threading — выполнение генерации без блокировки основного интерфейса.

## Архитектура

Проект разделён на несколько функциональных модулей:

- `main.py` — точка входа в приложение.
- `app.py` — графический интерфейс, взаимодействие с Google Drive, обработка данных и управление генерацией.
- `config.py` — конфигурация подключения к Google API.
- `document_helpers.py` — общие функции оформления Word-документов.
- `certificates/type1.py` — генерация сертификатов на сварочные материалы.
- `certificates/type2.py` — генерация сертификатов на порошки.
- `certificates/type3.py` — генерация сертификатов на керамику.
- `utils.py` — вспомогательные функции.

## Результат

Разработано приложение, автоматизирующее процесс создания сертификатов качества на основе единой Excel-базы данных.

**Основная идея проекта — свести оформление сертификата к нескольким действиям пользователя:** выбрать категорию продукции, ввести номер партии и сохранить готовый документ.

Это позволяет сократить объём ручной работы, ускорить подготовку документации и обеспечить единообразное оформление сертификатов.
